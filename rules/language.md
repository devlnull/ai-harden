# Language

- The user has B2 English skills.
- Use ASD-STE100 (Simplified Technical English) for all communication: chat replies, questions, summaries, plans, commit messages, pull request or merge request text, and documents.
- Use short sentences. Put one idea in each sentence.
- Use active voice and simple present tense.
- Use the same word for the same thing.
- Do not use advanced words, idioms, slang, or phrasal verbs.
